# Snack App 交互原型

[在线预览](https://sweemondr.github.io/snack-app-prototype/)

Snack 移动端交互演示，包含聊天、持续跟进、日程和资料，底部同时显示图标与名称。

## 预览

下载或克隆仓库后，直接用浏览器打开 `index.html`。页面所需的样式、脚本、Logo 和图标均已内嵌，无需安装依赖。

需要通过本地服务预览时，在仓库目录运行：

```sh
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>。

## 当前交互

- 聊天加号打开输入框上方的附件浮窗，选择图片或文件；支持发送前移除附件、语音输入与发送切换。
- 持续跟进模板按数据变动、定时、日程到达三类触发拆解；异常与恢复合并。文件生成、会议记录读取和钉钉通知分别列出，最后确认才创建目标。
- 持续跟进右上角加号打开说明抽屉，点击「前往对话」描述目标，无需先选择提醒类型。
- 日程支持直接从钉钉或手机日历导入，授权后明确选择会议；也可在聊天中添加。会前准备、会后持续跟进默认开启，可在会议设置中分别关闭，历史内容保留。
- 会议详情展示基本信息与动态；不提供模拟行动、补充原文或录音操作入口。钉钉消息发送与资料读取独立授权。
- 资料分为「文件 / 记忆」。文件仅为系统产出提供每日简报、会前提醒、跟进记录、会后行动文件夹，按启用状态或已有产物出现；其余文件平铺，支持搜索与来源关联。
- 记忆按关于我、项目与业务、人物与协作、约定与决策组织，保留导入、编辑、来源和移除确认。
- 白色页面、橙色强调；实心橙色按钮使用白字，保留键盘操作及可访问名称。

## 演示边界

日程、授权、业务数据与 AI 处理使用预设数据或本地交互模拟，不执行真实业务授权或数据读取。上传仅保存文件名，不读取、上传或解析文件内容。交互状态保存在浏览器本地存储中。

当前副本来自 2026-11-17 浏览器批注修订的本地原型，内容与原 HTML 一致。
